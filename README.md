# ShaderEditorScreenSaver

Android screen-saver support for [markusfisch/ShaderEditor](https://github.com/markusfisch/ShaderEditor), based on Shader Editor **2.36.2** (`c00a91a8170f1cb9dc0cb6dfab578ef9cd5b817d`).

## Added functionality

- Android `DreamService` using Shader Editor's existing OpenGL `ShaderView` renderer.
- Separate saved shader for the screen saver (independent of the live wallpaper shader).
- **Set as screen saver / Update screen saver** action in Shader Editor's menu.
- Opens Android's system Screen Saver settings after selecting a shader.
- Falls back to another saved shader if the configured screen-saver shader is deleted.
- Built-in **Gravitational Clock v8** sample with smooth wall-clock seconds, asymmetrical gravitational lensing, warped spacetime fabric, and luminous hour/minute geodesics.

## Branches

- `main` — patch/source inputs and APK build automation.
- `screensaver-source` — full modified Shader Editor source, generated by the build workflow after a successful build.

## Build

The GitHub Actions workflow checks out the pinned upstream Shader Editor release, applies the screen-saver and Play Protect compatibility patches, installs the maintained Gravitational Clock shader from `samples/gravitational_clock_v8.glsl`, validates the GLSL, builds `:app:assembleDebug`, uploads the APK artifact, and publishes the resulting full source to `screensaver-source`.

Current Actions artifact name: `ShaderEditor-GravitationalClock-v8-debug`.

> GitHub Actions artifacts are build artifacts rather than permanent public release downloads. For a visitor-friendly APK download, publish the APK as a GitHub Release asset.
